- 收到 v0.2.0 真机仍有开屏与信息流广告的反馈后，对照用户 QX 配置启用的墨鱼 WeiboAds.conf，撤回自写字段处理。

- open_app 使用上游详情横幅处理；不再自行修改五个推测的广告开关。
- 补齐时间线、卡片、新版信息流、PHP/Lua SDK 入口，以及实时开屏、专用广告接口和 SDK 配置复写。
- 保留 QX 的 SDK DIRECT 与两个专用广告域名拒绝条目；MitM 扩为 11 个精确主机。
- 未接入上游会员皮肤、个人主页及搜索页整体改造；信息流仍会沿用上游对部分推荐和热推的清理。
- 删除 v0.2.0 自写脚本及旧测试，新增 11 项直接运行固定上游脚本的测试，全部通过。
- 私有抓包 101 条记录回放，匹配并修改 4 条，无脚本异常，其余 97 条不匹配。信息流没有真实广告卡片样本，真机效果待验证。
- 明确插件参数不控制固定分流和 MitM，完整回退需停用插件；提示避免重复微博插件、检查脚本下载及实际命中。

## v0.2.0 — 2026-10-26

- 新增微博国际版补充模块：3 条 Script v2、1 个脚本、2 个精确 MitM 主机。
- 清空成功的开屏预加载响应中的 ads 数组，保留返回码和时序配置。
- 在当前实际使用的 weibointl.api.weibo.cn 主机处理 get_coopen_ads；关闭 display_ad，并清空已存在且为数组的广告素材列表。
- 对 open_app 中观察到的五个信息流/热门/搜索广告开关做 1 → 0 调整；提供独立开关。
- 不过滤普通微博正文，不修改登录和会员数据；未知格式、错误状态和解析失败均保持原响应。
- 10 项合成测试通过；本地私有抓包回放只改动 4/101 个响应，两次开屏列表为 16 → 0、15 → 0。
- 信息流时间线正文未被本次抓包覆盖，实际信息流去广告及客户端兼容性待真机验证。
- 公开提交仅包括通用规则、脚本、合成测试与说明，不包含原始抓包或凭据。
