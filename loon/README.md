# Loon：奶思基础 + 机场自动 + 家宽出口

当前公开模板：**2026.11.25-r3**。日常只维护一份主配置，去广告默认只加载奶思 `blockAds.plugin`。

```text
手机 → 机场自动（云梯 + ikuuu 的亚洲专线候选）→ 家宽 SOCKS5 → 境外网站
```

## 机场与家宽维护

- 云梯、ikuuu 保留为两个独立远程订阅，在 Loon 的节点页面更新或编辑。
- `亚洲前置` 从节点名称筛选香港、日本、新加坡、台湾、韩国的 IEPL/IPLC/专线节点，并排除免费、下载、试用等标签。
- `机场自动` 每 600 秒测速，切换容差 50 ms；测速目标是机场节点自身，完整家宽链仍需实际请求检查。
- `境外家宽` 固定引用 `机场自动,家宽出口`。更新订阅后重新筛选候选，无需生成大量本地节点或代理链。
- 国内规则直连；Google、出口检查及境外兜底使用家宽链。保持分流模式。

## 去广告补充按需使用

当前精简方案先使用奶思。旧补充仍有独立的接口和字段处理，因此保留为可选资源：微博、高德、彩云、百度网盘、闲鱼、网易邮箱大师、汽水音乐、腾讯文档、淘票票、iDaily、中国联通、墨迹天气、车来了、微信素材。

需要其中的效果时再添加下面的固定地址，补充插件版本为 **v0.7.1**。本版只更新说明和核对基准，所有原有生效指令、开关和脚本保持。

```text
https://raw.githubusercontent.com/ShiinaWong/stash-configs/main/loon/shiina-adblock-supplement.plugin
```

首次安装仍沿用各应用开关默认开启的旧行为；按需关闭不用的项。停用整个插件可同时移除其分流与 MitM。避免同时启用相同 App 的另一套响应脚本。微信素材处理可能留下文字或占位；普通图片、视频异常时关闭该项对照。

[SideStore 本地回环](https://github.com/ShiinaWong/loon-plugins) 是独立功能，继续保留在原仓库；本主模板没有默认启用它。
