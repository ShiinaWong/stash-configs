# Shiina Loon 去广告补充

配合 fmz200（奶思）广告拦截&净化合集使用的独立补充插件。固定订阅地址不变，采用 Loon Rewrite v2 / Script v2。

## 当前版本：v0.6.0（2026-10-29）

以奶思 V2 为基础，本版参考墨鱼公开配置，补充中国联通、墨迹天气、车来了，并增加用户微信抓包中目视确认的四张度小满广告素材拦截。此前十组应用处理保持原状。联通和墨迹使用自有脚本；微信只拒绝已确认素材的精确路径。

| 应用 | 本版处理 | 使用时需要了解 |
| --- | --- | --- |
| 微博 | 保留 v0.3.0 的开屏、SDK、信息流处理 | 仍采用墨鱼原脚本；真机效果待反馈 |
| 高德 | 首页/附近/打车/我的页面、热词、角标和专用推广接口 | 沿用原脚本的精简，会隐藏部分推荐、AI 入口及页面卡片 |
| 彩云 | 首页推广、消息/活动弹窗、发现页推荐和外链入口 | 保留可识别的天气文章与原生功能链接；不植入固定文章 |
| 百度网盘 | 已知广告配置、首页推荐、任务推广、热搜/短剧入口 | 已识别的首页信息流保留文件功能和最近记录；未知格式保留 |
| 闲鱼 | g-acs 开屏、悬浮/搜索推广，以及商品底部明确标记的广告 | 奶思已有的信息流和推荐列表不重复接管；不删除未知类型商品卡片 |
| 网易邮箱大师 | 我的页运营推广、任务及悬浮入口 | 保留登录引导、扩展配置、账号资料和收发信接口 |
| 汽水音乐 | 广告请求、奖励广告横幅、热门搜索榜及活动推荐 | 会隐藏热门搜索榜；不处理歌曲流、TNC、付费接口 |
| 腾讯文档 | 专用 ad / advertise 路径 | 仅按 URL 路径拒绝，不读取或修改文档正文 |
| 淘票票 | 广告预加载、我的/影院横幅、首页轮播和启动营销弹窗 | 保留猜你喜欢、搜索配置和购票接口；专用弹窗接口清空 data |
| iDaily 系列 | iDaily/iDays 开屏、弹窗和同系应用交叉推广 | 只处理作者列出的广告接口；保留新闻和日历正文 |
| 中国联通 | 热搜推广、营销背景、商城角标、新人推广 | 保留钱包、积分、账户、客服及首页业务脚本 |
| 墨迹天气 | 浮窗、商品推广、banner 区 | 保留工具、灯泡入口、发现页和短视频；仅限 api.moji.com 子域名 |
| 车来了 | 推广位、详情信息流和缺少的广告接口 | 保留公交查询、路线规划和原有底栏；不封共享 IP |
| 微信度小满素材 | 三张广告横幅和一张品牌客服图 | 仅四个确认的素材路径；更换素材不会自动覆盖，文字或空白占位可能仍在 |

本版新增 2 条响应脚本、10 条请求复写和 7 个 MitM 条目。总计 18 条响应脚本、30 条请求复写、3 条原有微博分流、38 个 MitM 条目（37 个精确主机及 `*.api.moji.com`）。墨迹通配范围来自作者配置，URL 规则同时排除奶思已拒绝的 me/ad/fds 主机。最低版本为 **Loon 3.5.1（983）**。

## 安装或更新

固定插件地址：

```text
https://raw.githubusercontent.com/ShiinaWong/stash-configs/main/loon/shiina-adblock-supplement.plugin
```

[一键导入 Loon](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2FShiinaWong%2Fstash-configs%2Fmain%2Floon%2Fshiina-adblock-supplement.plugin)

已安装时更新原来的「Shiina 去广告补充（V2）」插件，确认描述显示 **v0.6.0**。确保新脚本下载成功、MitM 已启用、Loon 证书已安装并信任。无需重复添加插件或替换整份配置。

本版四个新增开关默认开启，可以独立关闭。微信开关名为「微信度小满广告素材」；它不能代替小程序广告数据接口净化。更新后退出并重新打开要验证的 App，检查广告位置和常用功能。基础奶思、Shiina 补充同时启用；之前试装的同 App 墨鱼专用去广告插件先停用，避免重复处理。可莉广告平台拦截器和 HTTPDNS 拦截器可继续保留，出现异常时按插件或应用开关分别对照排查。

日志可按以下脚本标签识别实际命中：

- `Shiina-高德-墨鱼页面净化`

- `Shiina-网盘-页面推广`
- `Shiina-闲鱼-搜索与悬浮推广` / `Shiina-闲鱼-商品推荐广告`
- `Shiina-邮箱大师-页面推广`
- `Shiina-汽水音乐-页面推广`
- `Shiina-淘票票-推广补充`
- `Shiina-iDaily-交叉推广`
- `Shiina-中国联通-营销补充`
- `Shiina-墨迹天气-横幅补充`

腾讯文档、车来了及微信素材采用请求拒绝，没有正文脚本标签，需查看相应 URL 的拒绝记录。微信应观察 `wximg.wxs.qq.com` 下已确认素材是否出现拒绝记录；普通微信图片不应全部被拒绝。

## 与奶思搭配

奶思继续独立订阅。本版对照其固定公开版本检查新增请求和响应入口，避开已覆盖的闲鱼信息流、邮箱通用广告、汽水 card / more-panel 和淘票票开屏。旧版避让的高德 valueadded、彩云 activity 和百度通用广告接口保持原状。本版再避开奶思已有的墨迹广告域名、车来了 api/adpub 等处理。审计基准、完整取舍见[第四批适配记录](docs/moyu-fourth-batch.md)、[微信素材记录](docs/wechat-dxm-assets.md)和[第三批适配记录](docs/moyu-third-batch.md)。

Loon 同一响应只选择第一条命中的响应脚本；请求拒绝和响应正文复写也可能阻止脚本执行。若另有同 App 专用插件、Script-Hub 转换规则或本地复写，需要再检查重复项，单纯调整插件排序不能解决所有冲突。

本次静态审查还发现奶思 V2 的部分 `enable=参数名` 写法与官方文档的 `enable=${参数名}` 不一致。是否影响手机实际加载须以当前版本和解析日志为准，不能仅凭源码断言全部失效。本补充使用官方参数引用写法，并不自动修改奶思本身。详见[第二批适配记录](docs/qx-second-batch.md)。

## 开关和回退

- 「微博净化脚本与复写」及「微博信息流与详情广告」保留原含义。
- 「高德页面净化」「彩云页面净化」「网盘页面净化」分别控制本插件相应的 Script / Rewrite。
- 「闲鱼广告补充」「网易邮箱大师推广」「汽水音乐推广」「腾讯文档广告」「淘票票推广」「iDaily 系列推广」保持 v0.5.0 含义。
- 新增「中国联通推广」「墨迹天气推广」「车来了广告补充」「微信度小满广告素材」，各自控制对应 Script / Rewrite。
- 应用出现异常时先关闭对应应用开关，重新打开 App 对照。
- 参数不移除固定分流和 MitM。需要完整回退时停用整个补充插件。
- 已缓存的广告或配置不会因更新立即清除，可使用 App 自带清理缓存功能；不要求先卸载应用。

## 验证与范围

**57 项离线测试通过**：原有 41 项回归、12 项第四批测试和 4 项微信素材测试。验证接口边界、独立开关、业务错误保留、正常内容保留、幂等性，以及与固定奶思版本的静态重叠检查。第四批使用 4 个响应 URL、15 个请求 URL 作为代表性合成样例；合成墨迹主机不代表观察到的真实主机。

微信私有抓包共 583 条请求，本版素材规则匹配其中 6 次请求，涉及 4 张目视确认的图片；其余 577 条不匹配该新增规则。只发布去掉查询参数的共享广告素材路径及合成测试，不发布素材图片、原始请求头或抓包。`mp/getainfo` 返回文章链接信息，本版不修改；另一个游戏视频及未确认素材没有纳入度小满规则。

这些是 Node.js 合成测试、静态检查和私有 URL 匹配回放，未运行 Loon 官方解析器，也不等同于手机广告已全部消失。联通、墨迹、车来了没有本轮真机响应样本；微信未获得可安全修改的广告卡片数据接口，素材拦截可能留下文字、空白区域或触发其他素材。JSONP、加密响应和未采用的接口不在本版处理范围内。

本次只发布补充插件、通用脚本、合成测试和说明；代理链、机场订阅、DNS、完整个人配置以及原始抓包均不属于发布内容。
