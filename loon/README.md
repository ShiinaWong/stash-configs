# Shiina Loon 去广告补充

配合 fmz200（奶思）广告拦截&净化合集使用的独立补充插件。固定订阅地址不变，采用 Loon Rewrite v2 / Script v2。

## 当前版本：v0.7.0（2026-10-30）

以奶思 V2 为基础，本版将微信从四张度小满素材 ID 拦截升级为同类广告图片与视频的路径匹配。不同品牌、更换素材 ID、已覆盖格式的图片变体可以自动匹配；广告卡片文字和占位仍不保证移除。其他十三组应用处理保持 v0.6.0。

| 应用 | 本版处理 | 使用时需要了解 |
| --- | --- | --- |
| 微博 | 保留 v0.3.0 的开屏、SDK、信息流处理 | 仍采用墨鱼原脚本；真机效果待反馈 |
| 高德 | 首页/附近/打车/我的页面、热词、角标和专用推广接口 | 沿用原脚本的精简，会隐藏部分推荐、AI 入口及页面卡片 |
| 彩云 | 首页推广、消息/活动弹窗、发现页推荐和外链入口 | 保留可识别的天气文章与原生功能链接；不植入固定文章 |
| 百度网盘 | 已知广告配置、首页推荐、任务推广、热搜/短剧入口 | 已识别的首页信息流保留文件功能和最近记录；未知格式保留 |
| 闲鱼 | g-acs 开屏、悬浮/搜索推广，以及商品底部明确标记的广告 | 奶思已有的信息流和推荐列表不重复接管；不删除未知类型商品卡片 |
| 网易邮箱大师 | 我的页运营推广、任务及悬浮入口 | 保留登录引导、扩展配置、账号资料和收发信接口 |
| 汽水音乐 | 广告请求、奖励广告横幅、热门搜索榜及活动推荐 | 会隐藏热门搜索榜；不处理歌曲流、TNC、付费接口 |
| 腾讯文档 | 专用 ad / advertise 路径 | 仅按 URL 路径拒绝，不读取或修改文档正文 |
| 淘票票 | 广告预加载、我的/影院横幅、首页轮播和启动营销弹窗 | 保留猜你喜欢、搜索配置和购票接口；专用弹窗接口清空 data |
| iDaily 系列 | iDaily/iDays 开屏、弹窗和同系应用交叉推广 | 只处理作者列出的广告接口；保留新闻和日历正文 |
| 中国联通 | 热搜推广、营销背景、商城角标、新人推广 | 保留钱包、积分、账户、客服及首页业务脚本 |
| 墨迹天气 | 浮窗、商品推广、banner 区 | 保留工具、灯泡入口、发现页和短视频；仅限 api.moji.com 子域名 |
| 车来了 | 推广位、详情信息流和缺少的广告接口 | 保留公交查询、路线规划和原有底栏；不封共享 IP |
| 微信通用广告素材 | wximg 已知素材目录、wxsmw 带广告前缀的视频 | 按主机及路径识别，不识别品牌；可能留文字或占位，异常可单独关闭 |

本版将 1 条微信图片规则替换为 2 条媒体类型对应的规则，并新增 1 个精确 MitM 主机。总计 18 条响应脚本、31 条请求复写、3 条原有微博分流、39 个 MitM 条目（38 个精确主机及 `*.api.moji.com`）。微信没有增加响应脚本；图片返回 1×1 GIF，视频返回空白视频。最低版本为 **Loon 3.5.1（983）**。

## 安装或更新

固定插件地址：

```text
https://raw.githubusercontent.com/ShiinaWong/stash-configs/main/loon/shiina-adblock-supplement.plugin
```

[一键导入 Loon](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2FShiinaWong%2Fstash-configs%2Fmain%2Floon%2Fshiina-adblock-supplement.plugin)

已安装时更新原来的「Shiina 去广告补充（V2）」插件，确认描述显示 **v0.7.0**。确保新脚本下载成功、MitM 已启用、Loon 证书已安装并信任。无需重复添加插件或替换整份配置。

微信开关现在显示为「微信通用广告素材」，保留旧参数名，继承原来「微信度小满广告素材」的开关选择。首次安装默认开启；此前手动关闭过的用户需要手动开启。它仍属于素材处理，不能代替广告卡片数据接口净化。更新后退出并重新打开要验证的 App，检查广告位置和常用功能。基础奶思、Shiina 补充同时启用；之前试装的同 App 墨鱼专用去广告插件先停用，避免重复处理。可莉广告平台拦截器和 HTTPDNS 拦截器可继续保留，出现异常时按插件或应用开关分别对照排查。

日志可按以下脚本标签识别实际命中：

- `Shiina-高德-墨鱼页面净化`
- `Shiina-彩云-页面推广`
- `Shiina-网盘-页面推广`
- `Shiina-闲鱼-搜索与悬浮推广` / `Shiina-闲鱼-商品推荐广告`
- `Shiina-邮箱大师-页面推广`
- `Shiina-汽水音乐-页面推广`
- `Shiina-淘票票-推广补充`
- `Shiina-iDaily-交叉推广`
- `Shiina-中国联通-营销补充`
- `Shiina-墨迹天气-横幅补充`

腾讯文档、车来了及微信素材采用请求拒绝，没有正文脚本标签，需查看相应 URL 的拒绝记录。微信应观察 `wximg.wxs.qq.com` 的指定目录及 `wxsmw.wxs.qq.com` 的广告视频是否命中复写。由于返回的是 HTTP 200 占位媒体，只筛选失败请求可能看不到命中，需要检查具体请求的复写信息或响应；不能仅凭 200 判定未处理。

## 与奶思搭配

奶思继续独立订阅。本版对照其固定公开版本检查新增请求和响应入口，避开已覆盖的闲鱼信息流、邮箱通用广告、汽水 card / more-panel 和淘票票开屏。旧版避让的高德 valueadded、彩云 activity 和百度通用广告接口保持原状。v0.6.0 避开的墨迹广告域名、车来了 api/adpub 等处理继续保持。本版微信规则与核对的奶思快照没有发现相同入口重叠。审计基准、完整取舍见[第四批适配记录](docs/moyu-fourth-batch.md)、[微信素材记录](docs/wechat-dxm-assets.md)和[第三批适配记录](docs/moyu-third-batch.md)。

Loon 同一响应只选择第一条命中的响应脚本；请求拒绝和响应正文复写也可能阻止脚本执行。若另有同 App 专用插件、Script-Hub 转换规则或本地复写，需要再检查重复项，单纯调整插件排序不能解决所有冲突。

本次静态审查还发现奶思 V2 的部分 `enable=参数名` 写法与官方文档的 `enable=${参数名}` 不一致。是否影响手机实际加载须以当前版本和解析日志为准，不能仅凭源码断言全部失效。本补充使用官方参数引用写法，并不自动修改奶思本身。详见[第二批适配记录](docs/qx-second-batch.md)。

## 开关和回退

- 「微博净化脚本与复写」及「微博信息流与详情广告」保留原含义。
- 「高德页面净化」「彩云页面净化」「网盘页面净化」分别控制本插件相应的 Script / Rewrite。
- 「闲鱼广告补充」「网易邮箱大师推广」「汽水音乐推广」「腾讯文档广告」「淘票票推广」「iDaily 系列推广」保持 v0.5.0 含义。
- 「中国联通推广」「墨迹天气推广」「车来了广告补充」保持 v0.6.0；「微信通用广告素材」控制新增的图片与视频占位响应。
- 应用出现异常时先关闭对应应用开关，重新打开 App 对照。
- 参数不移除固定分流和 MitM。需要完整回退时停用整个补充插件。
- 已缓存的广告或配置不会因更新立即清除，可使用 App 自带清理缓存功能；不要求先卸载应用。

## 验证与范围

**61 项离线测试通过**：其他应用 53 项回归，以及更新后的 8 项微信测试。验证原四张素材仍覆盖、新素材 ID 与变体、两种媒体动作、普通业务路径、主机伪匹配、查询参数误匹配、开关关闭和奶思静态重叠。

在已有微信抓包的 583 条请求中，新规则匹配 16 次（14 次图片请求、2 次广告视频请求），对应 13 个不同路径；原 v0.6.0 匹配的 6 次请求仍全部覆盖。其余 567 条不匹配这两条规则。匹配的记录里只有 5 张图片及 2 段视频响应可检查，其中一个视频响应只有 2 字节，不能把 16 次匹配理解为 16 个已验证移除的广告。

图片规则的通用性来自已观察到的目录及公开过滤器的路径规则，这是路径归纳，不是服务端对每个资源的广告标注。新目录、新域名、加密广告数据、缓存素材和卡片占位可能漏过；同目录未来混入普通资源也可能误伤。若普通图片或视频异常，先关闭「微信通用广告素材」对照。

这些是 Node.js 合成测试、静态检查和私有 URL 匹配回放，未运行 Loon 官方解析器或更新后真机验证。联通、墨迹、车来了等上一批功能没有本轮新增响应样本。JSONP、加密响应和未采用的接口不在本版处理范围内。

本次只发布补充插件、通用脚本、合成测试和说明；代理链、机场订阅、DNS、完整个人配置以及原始抓包均不属于发布内容。
