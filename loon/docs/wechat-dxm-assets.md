# 微信度小满广告素材补丁

版本：v0.6.0，2026-10-29。基于用户提供的微信抓包分析；原始 ZIP、图片、请求头、查询参数及正文均不进入仓库。

## 本次能够确认的范围

抓包中可读取的 `wximg.wxs.qq.com` 图片经目视确认，包含三张带「度小满」品牌的贷款广告横幅，以及一张带该品牌标识的客服图。新规则仅匹配这四张素材的完整主机和路径，使用请求拒绝；不通过某个关键词封锁整个微信图片服务。

广告图片的共享素材标识保留在通用规则中，捕获的签名、时间、追踪和认证查询参数不发布。规则可匹配相同素材的新查询参数，但不会扩展到未知素材或未知变体。

此外，抓包中还见到游戏广告视频及无法确认品牌的客服头像，未纳入本次度小满规则。`mp.weixin.qq.com/mp/getainfo` 返回的 `ainfos` 是文章链接信息，样本为 `LINK_TYPE_MP_APPMSG`；不能根据接口名称将其清空。该接口、文章正文、头像服务及微信二进制通信没有新增拦截。

## 实现与验证

- 新增独立开关「微信度小满广告素材」，默认开启。
- 新增 1 条 Rewrite v2 请求拒绝和 1 个精确 MitM 主机 `wximg.wxs.qq.com`。
- 没有新增微信响应脚本，也没有全域名 REJECT。
- 私有抓包的 583 条请求中，新规则匹配 6 次请求，涉及这 4 张图片；4 次有可供目视核对的响应体，另 2 次为相同素材的重复请求。其余 577 条不匹配该新增规则。
- 4 项离线测试覆盖已确认路径、不同查询参数、相邻/伪造主机、普通图片及微信业务放行，并与固定奶思 V2 检查静态重叠。

此处回放指本地执行 URL 匹配，没有重发抓包请求、访问私有链接或模拟登录。合成测试仅使用共享广告素材路径及虚构查询参数。

## 效果限制与手机验证

这是素材拦截，不是广告卡片数据清理。未获得可安全修改的卡片 JSON 接口；请求仍可能经过微信的二进制通信。拦截素材后可能留下广告文字、按钮、空白占位，或触发其他广告素材。新素材 ID 不会自动命中这四个路径。

更新原来的「Shiina 去广告补充（V2）」并确认显示 v0.6.0，保持 MitM 与证书信任正常，退出小程序后重新打开验证。观察 Loon 是否拒绝已确认的 `wximg.wxs.qq.com` 素材路径，同时验证普通图片能正常显示。

若广告仍在，请提供广告位置截图及再次出现时的抓包，用来区分缓存、新素材和仍保留的卡片占位，不直接扩大成整域名屏蔽。原始抓包继续只作私有分析。

如遇图片加载异常，可先关闭「微信度小满广告素材」对照；开关只停用该 Rewrite，MitM 条目仍在。完整停用该插件需关闭整个 Shiina 补充。
