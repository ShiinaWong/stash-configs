# 家宽出口手动检测

当前入口 v1.0.0，随主配置 **2026.11.25-r6** 加入。使用 MaYIHEI 的 IPQuality 检测核心；为本方案提供三个轻量手动入口。

## 手机使用

1. 选择 `Loon_奶思家宽_2026.11.25-r6.lcf`，保持分流模式并连接 VPN，更新插件。
2. 从 Loon 的手动脚本入口运行 **家宽检测 · 基础信息**；也可从节点或策略页的脚本入口运行。检测始终沿用当前业务分流，与入口点选的机场节点无关。
3. 按需运行 **家宽检测 · 风险** 或 **家宽检测 · 流媒体与 AI**。每次最多约一分钟；数据源可能部分不可用。
4. 报告默认隐藏 IP。需要确认出口是否为购买的家宽时，在自己的设备上与出口检查网页对照；无需发送 IP、账号或密码。

当前主配置为国内直连、境外家宽；检测沿用这些规则。启动前核对运行模式与最终策略，配置不符时停止并给出提示。报告里的风险标签和地区信息来自查询服务，真实登录、注册和播放效果以对应应用为准。

## 与原作者版本的关系

作者的[维护入口与完整网页检测版](https://github.com/MaYIHEI/paperclip/tree/main/loon/ipquality-web-test)提供更多网页检测项目。本次按现有家宽方案采用其中基础、风险、流媒体与 AI 三组检测，直接下载并运行同一[固定检测核心](https://github.com/MaYIHEI/paperclip/blob/eaa04fe0a9f37ccfafdd11930d28fd5ff3f04718/loon/ipquality/ipquality.js)。核心没有复制进此仓库。

核心版本 `2026-07-22.r32`，Git blob SHA `ed957937796f7f1ed1a2fa2a27de1a973bd18dc7`。作者为 MaYIHEI，原文件亦注明参考 Roddy-D 与 xykt。

此处的薄适配负责四件事：

- 选择三个手动检测项目；不包含定时任务和网络变化触发任务。
- 移除检测请求的显式 `DIRECT` 或单节点指定，让探测及数据库查询全部沿用当前分流。原作者的数据库查询部分会指定直连，本方案保持用户的现有路由。
- 开启原核心的 IP 遮罩，禁止脚本日志输出原始请求、接口错误和响应正文。
- 保留正常 TLS 证书校验；启动前检查分流模式和最终策略，防止在错误配置下运行。

插件本身仅含 `[Script]` 三个 Generic 指令，不增加代理组、链、分流、DNS、MitM 或证书，也不会读取、上传机场订阅及家宽凭据。检测会向 IP 查询服务查询出口属性、向对应媒体/AI 服务发起探测，这是检测本身的工作方式。

本版不包含原完整版的网页报告入口、三网探针、BGP、MTR、测速等扩展项目；当前目标是便捷检查日常家宽出口。

## 更新与回退

固定插件地址：

```text
https://raw.githubusercontent.com/ShiinaWong/stash-configs/main/loon/shiina-ipquality.plugin
```

日常刷新这个插件即可更新入口。此地址及 r5 已使用的 Shiina 功能补充地址保持固定，普通插件内容更新无需再更换主配置。

r6 首次增加第三个插件条目，所以此次需切换主配置。配置目录保留 r6 与 r5 原样备份；切回 r5 或停用本检测插件即可撤回。SideStore 保持未启用。

## 验证

77 项离线测试通过，其中 7 项新增验证覆盖：只含手动入口、模式和最终策略检查、无效项目、固定核心哈希、原核心基础/风险/媒体报告、清除显式节点覆盖、TLS 校验、IP 遮罩、下载及探测异常、日志与持久化写入限制。

使用合成响应执行真实固定核心，没有发出实际出口查询。手机端网络、接口可用性和报告结果仍待实际运行确认。离线测试可用 `IPQUALITY_CORE` 指向原文件；未设置时测试下载固定公开版本并校验哈希。
